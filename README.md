# StudyBloom 🌸

Личный учебный ежедневник: React + TypeScript, FastAPI, PostgreSQL, Docker Compose.

## Запуск на Linux

Установите Docker Engine и Docker Compose plugin. Затем из корня проекта:

```bash
docker compose up --build -d
```

Откройте http://localhost:5173 (интерфейс) и http://localhost:8000/docs (API).

Остановка: `docker compose down`.

## Текущий статус

Реализованы личные аккаунты по логину/паролю и изоляция данных; задачи с приоритетом,
поиском, фильтрами и JSON-экспортом; предметы и дедлайны; календарь месяца/недели
с событиями и редактированием; недельные шаблоны занятий; Pomodoro с паузой,
восстановлением и историей; привычки с целями и сериями; обзор и недельный график
концентрации. Интерфейс адаптирован под телефон в стиле «Уютный ежедневник».

Старые записи без владельца сохранены без автоматического присвоения аккаунтам.
Ограничения: исключения праздничных занятий и автоматическое отображение занятий
в календарной сетке ещё не добавлены; Pomodoro сохраняется явным нажатием по истечении
времени. Linux VM в UTM на пользовательском Mac ещё предстоит установить и проверить.

Подробности: [аккаунты](docs/ACCOUNTS.md), [расписание](docs/TIMETABLE.md),
[Pomodoro](docs/POMODORO.md), [привычки](docs/HABITS.md), [аналитика](docs/DASHBOARD.md).

План и фактический прогресс: [PROJECT_STATUS.md](PROJECT_STATUS.md).
Инструкция демонстрации: [docs/LINUX_DEMO.md](docs/LINUX_DEMO.md).

## Проверки

```bash
python -m venv .venv
.venv/bin/pip install -r backend/requirements-dev.txt
cd backend
../.venv/bin/python -m pytest -q
cd ../frontend
npm ci
npm test
npm run build
```

Для frontend-тестов нужен Node.js 22.18+ (или Node.js 24).
GitHub Actions проверяет API, frontend-тесты/сборку, браузерные сценарии на телефоне,
PostgreSQL и запуск Docker на Ubuntu. Docker smoke проверяет новые личные модули
и сохранность после перезапуска backend.

## Доступ преподавателю

Для доступа с другого устройства в той же сети откройте `http://IP_НОУТБУКА:5173` и убедитесь, что брандмауэр разрешает порт 5173. Не публикуйте порт БД и не используйте демонстрационный пароль для публичного развёртывания.

## ИИ и коммиты

При использовании ИИ отмечайте фактически использованную модель в описании соответствующего коммита, `При разработке использована модель ИИ: OpenAI GPT-6.`.
