# Повторяющиеся задачи

Создай шаблон с названием, приоритетом, датой начала и шагом день/неделя/месяц.
Конечная дата необязательна. Выбери период от1 до93 календарных дней и нажми
«Создать задачи за период». Только это действие создаёт обычные задачи с датой
повторения в названии. Фонового расписания нет; дата в названии не является дедлайном.

Недельный шаг отсчитывается от начальной даты. Месячный сохраняет исходное число:
31 января →28/29 февраля →31 марта. Границы начала и конца включаются.
Повтор запроса не создаёт копий. Даже после явного удаления задачи дата остаётся
учтённой, чтобы запрос не восстанавливал удалённое без намерения пользователя.

Пауза запрещает новую генерацию, но сохраняет все прежние задачи и историю.
Правило шаблона неизменно; для другого правила создай новый шаблон и приостанови старый.
Галочки и чек-листы созданных задач работают независимо. Шаги не копируются из шаблона.

API требует входа: GET/POST `/api/recurring-tasks`, PATCH `/{id}` с paused,
POST `/{id}/generate` с from_day/through. Чужие id404, пауза409, неверный период422.
Новые таблицы не меняют прежних владельцев. Уникальный ключ шаблон+день и блокировка
шаблона PostgreSQL защищают от одновременной генерации; конфликт можно безопасно повторить.
