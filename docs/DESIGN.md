# Уютный ежедневник

Выбран пользователем 16 ноября 2026: концепт №3.

- Кремовая бумага и деликатная точечная сетка.
- Пыльно-розовые акценты, бордовые заголовки, шалфейные вторичные элементы.
- Georgia для заголовков, системный sans-serif для форм и основного текста.
- Цветочный SVG-декор и небольшие акценты бумажного скотча; без внешних загрузок.
- Карточки с тонкой рамкой, небольшими тенями, достаточными отступами.
- На телефоне навигация сверху, панели в одну колонку; календарь прокручивается внутри панели.
- Сохранять видимый фокус и настройки уменьшенного движения.

Показывать только реальные данные. Будущие модули из концепта (Pomodoro, привычки,
расписание) добавляются по мере реализации; декоративный макет не является доказательством готовности.

Docker не нужен постоянно для разработки через GitHub. Для доступа к локальному
приложению Docker Engine и контейнеры должны быть запущены. На защите запускаем
сервис на выбранной Linux-машине, пока преподаватель им пользуется.
