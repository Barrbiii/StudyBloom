# Расписание

Занятия повторяются каждую неделю по выбранному дню (0 — понедельник, 6 — воскресенье)
в пределах starts_on/ends_on включительно. Это шаблоны расписания, не разовые события.
API: GET/POST /api/lessons, PUT/DELETE /api/lessons/{id}. Нужна сессия.
Поля: subject_id, weekday, starts_at, ends_at, starts_on, ends_on, room, teacher.
Время местное без timezone; окончание позже начала, ночные занятия разделяйте.
Предмет должен принадлежать текущему пользователю. Чужие id возвращают 404.
Нельзя удалить предмет, пока с ним связаны занятия. Прежние данные не переносятся.

В интерфейсе показаны все еженедельные шаблоны с их периодом, включая завершённые.
Исключения на праздники и автоматическое отображение занятий в календаре событий
пока не реализованы. Тесты API проверяют интервалы, владение и защиту предмета;
браузерный тест использует синтетические ответы, не заменяет проверку PostgreSQL.
