# Поиск, приоритеты и экспорт задач

Задачи имеют priority: low, normal или high. Прежние записи при миграции получают
normal; остальные поля сохраняются. Поле доступно в POST и PATCH /api/tasks.
GET /api/tasks принимает q, completed и priority; фильтры объединяются через И.
Поиск q — подстрока, % и _ рассматриваются буквально, а не как SQL-маски.
Фильтры применяются только к данным текущего владельца. q ограничен 255 символами.

Интерфейс фильтрует уже загруженные личные задачи по тексту, статусу и приоритету.
Поиск кириллицы не зависит от регистра. Есть сброс фильтров и сообщение при пустом
результате. Изменение приоритета сохраняется через PATCH.

Кнопка «Экспорт показанных задач» скачивает JSON именно выбранного списка.
Он содержит id, title, completed и priority, без owner_id, паролей или сессий.
Экспорт не является полной резервной копией PostgreSQL; импорт пока не реализован.
Перед передачей файла другому человеку проверьте содержащиеся в названиях данные.
