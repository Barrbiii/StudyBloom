# Привычки и ежедневные цели

Добавь ритуал, ежедневное число (1–10000) и единицу измерения. Например,
«Читать», 10, «страниц». Выбери день, введи результат либо нажми «Выполнено».
Повторное сохранение обновляет одну запись дня. «Снять отметку» сохраняет ноль.
Доступны сегодня и предыдущие 366 дней; будущие даты отклоняются сервером.
Часовой пояс берётся из устройства, сервер проверяет его как IANA-зону.

Норма дня фиксируется при первой отметке: изменение ежедневной цели применяется
к дням без записи. Старые успешные дни остаются успешными по прежней норме.
После первой отметки единицу измерения менять нельзя — для этого создай новый ритуал.
Привычку можно архивировать и вернуть. Архив не удаляет историю; отметки в архиве
запрещены. Удаления привычек нет, чтобы не потерять результаты случайным нажатием.

Текущая серия — последовательные успешные дни до сегодня; если сегодня ещё не
выполнено, учитывается серия до вчера. При пропуске вчера серия сбрасывается.
Лучшая серия и общее число успешных дней считаются по всей сохранённой истории.
Выбор старого дня в интерфейсе меняет редактируемый результат, но серии остаются
рассчитанными относительно сегодняшнего дня. История карточки показывает 30 дней.

API требует входа: GET/POST `/api/habits`, PUT `/api/habits/{id}`,
PUT `/api/habits/{id}/days/YYYY-MM-DD` с `value`, GET `/{id}/history?days=30`.
GET списка принимает `day`, маршруты дней принимают `tz` (по умолчанию Europe/Moscow).
Чужие id отвечают404. Таблицы новые; прежние данные не переносятся и не удаляются.

Проверки охватывают изоляцию, повтор отметки, архив, снимок цели, переход месяца/года,
пустую историю, смену дня в разных зонах, PostgreSQL и браузерную ширину360/390/768px.
