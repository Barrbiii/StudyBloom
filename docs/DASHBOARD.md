# Обзор и аналитика

«Учебная неделя» показывает собственные задачи за всё время, выполненные сегодня
активные привычки, число дедлайнов с прошедшей датой, до пяти ближайших дедлайнов
и занятия на сегодняшний день по недельным шаблонам в пределах периода действия.
Праздничные исключения в расписании пока не предусмотрены. Прошедшая дата дедлайна
не означает автоматически невыполненную работу: отдельного статуса сдачи ещё нет.

График концентрации охватывает семь календарных дней, включая сегодня, в часовом
поясе устройства. Учитываются завершённые сессии focus; отмены, перерывы и активные
сессии исключаются. Дата относится к моменту завершения, целиком в этот день.
Под графиком есть таблица точных значений для клавиатуры и экранного диктора.

Обзор обновляется после успешных изменений, возвращения на вкладку и по кнопке.
При ошибке вместо вымышленных нулей показывается сообщение и возможность повторить.
Записи без владельца и данные других пользователей исключены на сервере.
API: GET `/api/dashboard?tz=Europe/Moscow`; IANA-зона проверяется сервером.

Проверки: нулевое состояние, агрегации, изоляция двух аккаунтов, UTC-границы первого
дня недели и смена дня в Москве/Нью-Йорке, PostgreSQL, браузер обновления после записи,
ошибка503 и ширины360/390/768px.
