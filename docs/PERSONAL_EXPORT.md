# Личный архив учебных данных

После входа раздел «Твои планы — с тобой» скачивает JSON текущего аккаунта.
Формат studybloom-personal, version1. Включены все записи задач/шагов, предметов,
дедлайнов, событий, расписания, привычек/дней, сессий Pomodoro, шаблонов и дат повторений.
У записей сохранены id и ссылки внутри архива, даты и время; время UTC обозначено смещением.
Активная сессия экспортируется как состояние на момент архива, без cookie и active_owner.

Пароли, хеши паролей, логины, токены, чужие и прежние записи без владельца исключены.
Архив читается в PostgreSQL в отдельной read-only транзакции REPEATABLE READ:
параллельное изменение не должно дать смесь разных состояний связанных таблиц.
Ответ не кэшируется. Экспорт ничего не удаляет и не меняет.

Это переносимый личный архив, а не полная резервная копия PostgreSQL. Автоматического
импорта/восстановления пока нет: файл можно сохранить, изучить и использовать для
последующего восстановления после реализации/проверки импорта. Не удаляй рабочую БД,
полагаясь только на этот JSON. Резервная копия БД и проверка восстановления — отдельный этап.

GET `/api/export/study` требует сессию. Браузер проверяет скачанный JSON и повтор
после503; настоящий Docker-прогон проверяет содержимое первого и пустоту второго аккаунта.
PostgreSQL-тест добавляет запись из другой транзакции во время экспорта и проверяет снимок.
