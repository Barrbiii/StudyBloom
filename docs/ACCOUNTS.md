# Аккаунты: незавершённый этап

Ветка feature/accounts не готова для публичного использования и не должна
объединяться до изоляции учебных данных и проверки миграций.

Добавлены /api/auth/register, /login, /logout (POST), /me (GET).
Логин: 3–64 латинских символа, цифр или подчёркиваний; регистр не учитывается.
Пароль: 12–128 символов. Хранится scrypt-хеш с индивидуальной случайной солью.
Сессия на 24 часа: случайный токен хранится в HttpOnly SameSite=Strict cookie,
в базе хранится только SHA-256 токена. Выход отзывает текущую сессию.
Secure включён по умолчанию. Для локального HTTP потребуется явное
AUTH_COOKIE_SECURE=false; настройку ещё нужно включить в локальный Compose.
Запросы изменения аккаунта с Origin другого сайта отклоняются.

Осталось до готовности:
- добавить owner_id и фильтрацию всех задач, предметов, дедлайнов и событий;
- сохранить старые строки без автоматического назначения владельца;
- миграции на PostgreSQL и тесты изоляции двух аккаунтов;
- интерфейс регистрации/входа/выхода, очистка пользовательского состояния;
- ограничение попыток входа, очистка просроченных сессий;
- проверка HTTPS и proxy-заголовков для Origin за Nginx.

Эта основа НЕ защищает существующие учебные API. Не считать регистрацию
доказательством приватности данных. Существующие записи не изменяются.
