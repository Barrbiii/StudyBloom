# Аккаунты StudyBloom

Регистрация, вход, выход и просмотр профиля: POST /api/auth/register,
POST /api/auth/login, POST /api/auth/logout, GET /api/auth/me.
POST /api/auth/logout-all отзывает все сессии текущего пользователя.

Логин: 3–64 латинских символа, цифр или подчёркиваний, без учёта регистра.
Пароль: 12–128 символов; scrypt с индивидуальной солью.
Сессия: случайный токен, в базе только SHA-256, срок 24 часа. Cookie HttpOnly,
SameSite=Strict; Secure по умолчанию в API, локальный Compose явно отключает Secure
для HTTP. Для HTTPS-развёртывания задайте AUTH_COOKIE_SECURE=true.

Все учебные API требуют входа и фильтруются по owner_id. Чужой id возвращает 404.
Прежние строки сохраняются с NULL owner_id: новым аккаунтам они не выдаются.
Автоматического назначения владельца нет. Перед обновлением реальной базы сделайте
резервную копию. Аддитивная миграция и её повторный запуск проверяются отдельно
на PostgreSQL в одноразовой схеме CI.

Интерфейс открывается после проверки /me. При выходе или ответе 401 учебного API
он размонтируется и удаляет локальное состояние. Повторный вход загружает данные заново.

Nginx ограничивает вход и регистрацию по IP: 10 запросов в минуту, burst=5;
превышение даёт 429. В общей сети пользователи делят лимит IP.
API-порт 8000 опубликован только на loopback хоста; для сети используйте frontend 5173.
Прямой локальный доступ к API обходит лимит Nginx — не публикуйте backend наружу.

Проверки включают API двух пользователей, срок/отзыв сессий, UI входа и 401,
миграцию PostgreSQL, сборки и запуск Docker с проверкой HTTP 429.
Это учебное локальное развёртывание. Публичная эксплуатация требует отдельной
проверки TLS, резервного копирования и политики доступа инфраструктуры.
